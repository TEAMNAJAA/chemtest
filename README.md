# 🌱 ปฏิกิริยาการเกิดพอลิเมอร์ (Polymerization Reaction Game)

เว็บแอปพลิเคชันเกมการศึกษาเรื่อง **ปฏิกิริยาการเกิดพอลิเมอร์** แบบ Single Page Application
รองรับ Computer / iPad / Mobile (Responsive) — ไม่ต้องใช้ build tool ใด ๆ

---

## 🎮 วิธีเล่น

1. กด **“เข้าเล่นเกมเลย”** ที่หน้าแรก (ปุ่มนี้จะปลดล็อกระบบเสียงและเริ่มเพลง BGM)
2. อ่านโจทย์ในการ์ด **“โจทย์ Phase n”** — โจทย์สุ่มมาจากชุดข้อมูลทั้ง 3 แบบ
   - **Type 1** สารตั้งต้น → หา *พอลิเมอร์*
   - **Type 2** พอลิเมอร์ → หา *สารตั้งต้น*
   - **Type 3** ชื่อปฏิกิริยา → หา *สมการฉบับเต็ม*
3. เลือก **บัวรดน้ำ (ตัวเร่งปฏิกิริยา)** ให้ตรงชนิดปฏิกิริยา — ควบแน่น (เขียว) หรือ เติม (น้ำเงิน)
4. เลือกการ์ดคำตอบจาก **“ตัวเลือกคำตอบ”** 8 ใบ
   - **คอมพิวเตอร์**: ลากการ์ดไปวางในช่องคำตอบ (Drag & Drop)
   - **มือถือ / iPad**: แตะการ์ด 1 ครั้ง การ์ดจะวิ่งเข้าช่องว่างถัดไปเอง (หรือกดค้าง 0.2 วินาทีแล้วลากก็ได้)
   - แตะช่องคำตอบที่มีการ์ดอยู่ = เอาการ์ดคืนกอง
   - กดปุ่ม **“เมนู”** มุมซ้ายบนเพื่อกลับหน้าแรก (เวลาจะหยุดเดิน กด “เล่นต่อ” แล้วเล่นต่อจากเดิมได้)
5. กด **“ยืนยันคำตอบ”**
   - **ถูก** → ต้นไม้โตขึ้น 1 Phase + เอฟเฟกต์ประกาย
   - **ผิด** → ช่องคำตอบสั่น แล้วสุ่มโจทย์ใหม่
6. ปลูกครบ **3 Phase** = ส่งมอบผักให้ลูกค้า รับดาว ⭐ + เหรียญใบไม้ 🌿 แล้วรับลูกค้ารายใหม่

> ⚠️ **ตอบผิดติดกัน 3 ครั้ง** จะเจอ Jumpscare เต็มจอพร้อมเสียง `wow.mp3`
> กดปุ่ม “พยายามใหม่อีกครั้ง” เพื่อเล่นต่อ (ตัวนับจะถูกรีเซ็ตเป็น 0)

## ▶️ การเปิดใช้งาน

### วิธีที่ 1 — เปิดไฟล์ตรง ๆ
ดับเบิลคลิก `index.html` ได้เลย
(ในโหมด `file://` เบราว์เซอร์จะบล็อก `fetch()` ตาม CORS — เกมจะสลับไปใช้
ชุดข้อมูลสำรองที่ฝังไว้ใน `app.js` โดยอัตโนมัติ จึงเล่นได้ครบทุกโจทย์)

### วิธีที่ 2 — รันผ่าน local server (แนะนำ, จะอ่านไฟล์ CSV จริง)

```bash
npx serve .
```

หรือ

```bash
python -m http.server 8000
```

แล้วเปิด <http://localhost:8000>

### 🧪 ภาพสมการเคมีบนการ์ด (`assets/images/eq/`)

โจทย์และตัวเลือกคำตอบใช้ **ภาพสมการจริง** ไม่ใช่ข้อความ ทำให้อ่านง่ายกว่ามาก
โดยแปลงมาจาก `assets/imagesforselect/` (60 รูป = 20 ปฏิกิริยา × 3 ส่วน) ด้วยขั้นตอน

1. ทำพื้นขาวให้**โปร่งใส** (key ตามค่าความสว่าง) เพื่อวางทับกระดาษได้เนียน
2. **ลบเส้นตารางแนวนอน**ที่ติดมาจากการ crop (แถวบาง ๆ ที่ยาวเกือบเต็มภาพ)
3. ตัดขอบว่างออก แล้วขยาย 2 เท่าแบบ LANCZOS ให้คมเวลาแสดงบนการ์ด

| ไฟล์ | คือ |
|---|---|
| `r01-name.png` … `r20-name.png` | ชื่อปฏิกิริยา (พร้อมหมายเลข) |
| `r01-mono.png` … `r20-mono.png` | สารตั้งต้น (มอนอเมอร์) |
| `r01-poly.png` … `r20-poly.png` | พอลิเมอร์ |

การใช้ในแต่ละชนิดโจทย์

| ชนิด | โจทย์ | คำตอบบนการ์ด |
|---|---|---|
| Type 1 | `-mono` | `-poly` |
| Type 2 | `-poly` | `-mono` |
| Type 3 | `-name` | `-mono` → *(ตัวเร่ง)* → `-poly` เรียงบนลงล่าง |

สมการฉบับเต็มของ Type 3 **ประกอบขึ้นด้วย CSS** (ไม่ใช่รูปเดียว) โดยวางลูกศรและชื่อตัวเร่ง
จากตาราง `RXN_COND` ใน `app.js` คั่นกลาง — จึงคมทุกขนาดหน้าจอและแก้ข้อความตัวเร่งได้ง่าย

> การจับคู่ “แถวใน CSV → ปฏิกิริยาที่เท่าไร” อยู่ที่ตัวแปร `RXN_OF_ROW` ใน `app.js`
> (type 1 และ 3 เรียงตรงกับตาราง 1–20, ส่วน type 2 มี 16 ข้อ = `[1,2,6,7,8,10,11,…,20]`)
> ถ้าเพิ่ม/ลดแถวใน CSV ต้องแก้ตารางนี้ให้ตรงกันด้วย
> หากรูปโหลดไม่ขึ้น เกมจะสลับไปแสดง**ข้อความแทนอัตโนมัติ** (คลาส `art-failed`)

### รูปแบบไฟล์ CSV

| คอลัมน์ | ความหมาย |
|---|---|
| `ข้อ` | เลขข้อ |
| คอลัมน์ 2 | โจทย์ที่แสดงให้ผู้เล่นเห็น |

เพิ่ม/แก้โจทย์ได้โดยแก้ไฟล์ CSV ตรง ๆ (ถ้าค่าในช่องมีเครื่องหมาย `,` ให้ครอบด้วย `"…"`)
หากต้องการให้โหมด `file://` เห็นโจทย์ใหม่ด้วย ให้แก้ค่าในตัวแปร `EMBEDDED_CSV` ที่ต้นไฟล์ `app.js` ให้ตรงกัน

## 🧩 ระบบภายใน

| ระบบ | รายละเอียด |
|---|---|
| **Data loader** | ลอง `data/*.csv` → `assets/data/*.csv` → ข้อมูลฝังใน `app.js` |
| **CSV parser** | รองรับ quoted field และ escaped quote (`""`) |
| **Audio** | `bgm.mp3` วนลูป, ถ้าโหลดไม่ได้จะสังเคราะห์เพลง Bossa/Chiptune ด้วย Web Audio API; SFX ทั้งหมดสังเคราะห์สด |
| **Mute** | บันทึกสถานะไว้ใน `localStorage` คีย์ `polymer.muted` |
| **รูปต้นไม้** | `assets/images/phaseN.png` — ถ้าไฟล์หาย จะวาด SVG ต้นไม้แทนอัตโนมัติ |
| **Jumpscare** | `assets/images/jumpscare-face.png` + `assets/audio/wow.mp3` — มี CSS/Web Audio fallback |
| **Input** | Pointer Events รองรับเมาส์ ปากกา และนิ้ว + คีย์บอร์ด (Tab / Enter / Space) |
| **Animation** | ทุก animation เลื่อนด้วย `transform` เท่านั้น ไม่ผูกกับ `opacity` เพื่อให้ยังมองเห็นองค์ประกอบได้แม้เบราว์เซอร์หยุดรัน animation (แท็บถูก throttle) |

## 📱 Responsive Breakpoints

| อุปกรณ์ | ความกว้าง | เลย์เอาต์ |
|---|---|---|
| Desktop | > 1024px | 3-Column Grid · การ์ดคำตอบ 2 คอลัมน์ |
| Tablet / iPad | 768 – 1023px | 2-Column Grid · การ์ดคำตอบ 2 คอลัมน์ |
| Mobile | < 768px | Vertical Stack · การ์ดคำตอบ **คอลัมน์เดียว** (ภาพสมการจะได้ใหญ่พออ่านออก) |

ข้อความบนปุ่ม “ยืนยันคำตอบ / ล้างทั้งหมด” เป็น **text จริง** (ลบตัวอักษรที่ฝังในรูปออกแล้ว)
จึงไม่ยืดผิดสัดส่วนเวลาปุ่มกว้างเต็มจอบนมือถือ

รองรับ `prefers-reduced-motion` และโหมดแนวนอนบนมือถือ
